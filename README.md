# Myql: Quantitative Pricing Engine

Object-oriented C++ pricing engine for the valuation of exotic derivatives (EQA, ELE) using Monte Carlo simulation. 

## Build Instructions

This project uses a standard Makefile for compilation. To build and run the engine, open your terminal and execute the following commands:

```bash
# Navigate to the source directory
cd Myql

# Compile the project
make

# Run the generated executable
./myql
